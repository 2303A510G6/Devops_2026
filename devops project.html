ML Methods
Algorithms used in the IoT-SHM system
CNN-VGG16
94%
Deep learning for leaf disease classification. 5 repetitions of 3×3 conv + ReLU + 2×2 max-pool. No manual feature extraction needed.
SVM
85–87%
Benchmark classifier. Gaussian kernel for multiclass. Hyperplane separates healthy vs diseased. Slowest to generalize on new samples.
MLP
85–86%
Multi-layer feed-forward ANN. 1 hidden layer (1.5× input neurons). Log-sigmoid activation. Back-propagation training.
TDNN
86%
Time Delay Neural Network. Like MLP but with delayed inputs X(n)+X(n+T). Tracks temporal variations in sensor data.
ANFIS
87%
Adaptive Neuro-Fuzzy. Sugeno-type system. 5 layers: fuzzification → predecessor → normalisation → consequent → accumulation.
Key mathematical formulas from the paper

NDVI (Normalized Difference Vegetation Index) — calculated from Landsat band 4 (Red) and band 5 (Near-Infrared):

NDVI = (NIR − Red) / (NIR + Red)

MLP Output:

Yo = Σ fk( Σ Σ (Xi·W1ij + bi)·W2jk )

Mean Square Error (MSE):

E = ½ · Σ (Yo^p − YT^p)²

Weight update rule (gradient descent):

W[n+1]j = W[n]j + μ · (ΔE / ΔW[n])

Network architecture

Star-of-stars topology: SHMU nodes → LoRaWAN gateway (single-hop, 900 MHz ISM) → Ethernet router → IoT-SHM server. LoRaWAN achieves 1.6 km range with low power and no intermediate relay nodes required. Packet Forwarder software on gateway handles all message relay. OTAA (Over-The-Air Activation) creates encrypted session between each SHMU and the server. Sensor extension board supports 3 analog inputs, 3 SDI-12 ports, up to 6 I2C sensors, and includes a boost DC converter (TPS61081) producing 12V for sensor power.

About the Paper
IEEE ICKECS 2024 — Divakar K M et al.
Paper title
From Ranch to Worldwide: Observing Soil Wellbeing Patterns
Proposes a big-data framework that integrates high-resolution remote sensing, IoT in-situ sensors, and machine learning to bridge farm-level soil monitoring with global-scale land suitability prediction.
Core contribution
Self-powered, ruggedized, portable IoT-SHM system
A novel soil health monitoring unit (SHMU) using LoRaWAN for long-range communication, solar energy harvesting for autonomous operation, GPS for geo-location, and VGG16 CNN achieving 94% disease classification accuracy on tomato leaves.

Key results

  • FCM + GLCM + CNN gives best performance
  • CNN accuracy: 94% (GLCM features), 96% (raw images)
  • Weighted moving average filter: 8–12% PSNR improvement
  • Histogram processing: 9% PSNR improvement over filter masks
  • FCM division: 1–2% improvement over KCM for all classifiers
  • PDR tested with 4–16 sensor packs over Bluetooth/WiFi/wired

Methodology pipeline

NIR camera captures leaf images → Noise removal (WMA filter) → Image segmentation (KCM / FCM) → Feature extraction (GLCM, LBP, LBGLCM, GLRLM, SFTA) → Classification (SVM, MLP, TDNN, ANFIS, CNN-VGG16) → Disease identification (5 types) → Real-time alert via cloud server app.
